# 兼容性规则

## 版本原则

- 新增可选字段属于向后兼容改动。
- 删除字段、修改字段类型、改变枚举含义属于破坏性改动。
- 客户端必须忽略尚不认识的服务端响应字段。
- 服务端在协议迁移期应继续接受上一正式客户端版本发送的字段。

## 时间和标识

- 网络传输时间统一使用 UTC ISO 8601 字符串。
- 客户端展示时转换为任务的 IANA 时区，缺省为 `Asia/Shanghai`。
- 任务、设备和账户使用 UUID；本地旧数字 ID 不进入同步协议。
- `revision=0` 只表示尚未上传的新本地任务，服务端持久化任务从 1 开始。

## 删除

已同步任务使用删除墓碑传播。尚未上传且 revision 为 0 的任务在本地直接移除，不发送 delete mutation。
