# 同步错误码

| 错误码 | 含义 | 客户端行为 |
| --- | --- | --- |
| `REVISION_CONFLICT` | 服务端版本已变化 | 保留本地修改并展示冲突处理入口 |
| `ENTITY_NOT_FOUND` | 目标实体不存在 | 停止自动重试，等待用户或恢复流程处理 |
| `ENTITY_DELETED` | 服务端任务已删除 | 保留本地副本作为冲突，不静默覆盖 |
| `ENTITY_ID_UNAVAILABLE` | ID 属于其他账户或不可用 | 记录拒绝原因，不使用相同 ID 重试 |
| `ACTIVE_TODO_LIMIT_REACHED` | 当前方案未完成待办已达上限 | 保留本地修改，提示用户完成、删除其他待办或更新权益后重试 |
| `SYNC_ENTITLEMENT_REQUIRED` | 当前方案不包含云端同步（HTTP 403） | 保留本地任务和待上传记录，不退出账户、不阻断离线操作 |
| `SYNC_RESET_REQUIRED` | 增量游标早于服务端保留起点 | 暂停上传，获取完整快照并保留本地待上传修改，成功后继续同步 |

免费版额度见 `config/free-limits.json`。达到已完成上限时，服务端按 `completedAt`（首次点击完成时间）淘汰最旧记录并同步删除；未完成上限只拒绝新增或恢复，不自动删除未完成待办。

认证、限流和参数错误以 OpenAPI HTTP 状态及服务端 `message` 为准。客户端日志不得记录访问令牌、刷新令牌、验证码或完整任务内容。
